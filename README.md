# 🛠️ Digitools - Premium Digital Solutions Platform

**Digitools** is a modern, high-performance web platform designed to showcase and sell premium digital products and tools. Built with a focus on user experience and speed, it provides a seamless interface for users to browse, filter, and manage their favorite digital assets.

---

## 🚀 Technologies Used

This project leverages the power of modern web development tools to ensure scalability and performance:

- **Frontend:** [React.js](https://reactjs.org/) (Vite)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- **JavaScript:** [JavaScript (ES6+)](https://262.ecma-international.org/6.0/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Notifications:** [React Toastify](https://fkhadra.github.io/react-toastify/)
- **State Management:** React Hooks (`useState`, `use`)

---

## ✨ Key Features

### 1. Dynamic Product Catalog
Browse through a curated list of digital tools with real-time data fetching. The platform uses dynamic rendering to display products with specific tags, pricing models (monthly/yearly), and detailed feature lists directly from a JSON data source.

### 2. Intelligent Tab Switching & Filtering
Experience a smooth transition between "Products" and "Cart" views using a custom-styled tab system. The UI intelligently toggles content visibility and button states based on user interaction, ensuring a clutter-free experience.

### 3. Interactive Shopping Cart System
A fully functional cart management system that allows users to:
- Add products with a single click.
- Prevent duplicate entries with smart validation.
- Real-time cart count indicators on the navigation tabs.
- Instant feedback using beautiful Toast notifications.
